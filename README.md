Idle Cookie Game (C++ / Siv3D)

A simple idle game inspired by Cookie Clicker built in C++ with Siv3D

Click the cookie to earn cookies. Buy upgrades to get more cookies. Get more cookies

## Features:
- Click the cookie to gain cookies
- Grandma can be bought that gives 1 cookie per second

## How to build

Requires the **Siv3D SDK** (0.6.16) & C++ Compiler 

1. Install the Siv3d SDK: https://siv3d.github.io/downloads/
2. Clone this repository
